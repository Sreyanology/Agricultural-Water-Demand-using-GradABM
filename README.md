# Agricultural-Water-Demand-using-GradABM
Using Differentiable Agent-Based Modelling to predict Water Demand for specific states in India
The model predicts water demand for irrigation in agriculture for the states of Punjab, West Bengal, and Maharashtra.
The districts are the agents for each state. The individual farmers are not taken as agents because the number of farmers is immense, and there is no proper data on the number of farmers in each district of each state.
